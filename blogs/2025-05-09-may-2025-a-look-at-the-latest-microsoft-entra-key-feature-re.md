<h2>Joyful May!</h2>
<p>Welcome to the May edition of our monthly newsletter, summarizing the latest news and developments in the exciting, ever-evolving world of Microsoft Entra.</p>
<h2>What went into General Availability (GA) since April 2025?</h2>
<ul>
<li><strong><a href="https://learn.microsoft.com/entra/workload-id/workload-identity-federation-config-app-trust-managed-identity">Use managed identities as federated credentials for Microsoft Entra applications</a></strong> &#8211; This feature eliminates the need to store and manage client secrets or certificates when using a Microsoft Entra application to access Microsoft Azure resources across tenants. </li>
</ul>
<h2>New in Public Preview</h2>
<ul>
<li>
<p><strong><a href="https://learn.microsoft.com/entra/identity/authentication/how-to-authentication-track-linkable-identifiers">Track and investigate identity activities with linkable identifiers in Microsoft Entra</a></strong> &#8211; Microsoft will standardize the linkable token identifiers and expose them in Microsoft Entra sign-in logs and in workload audit logs such as Exchange Online audit logs and Microsoft Graph activity logs. This helps security analysts and professionals track and investigate identity-related attacks.</p>
</li>
<li>
<p><strong><a href="https://learn.microsoft.com/graph/api/conditionalaccessroot-evaluate?view=graph-rest-beta&amp;tabs=http">Conditional Access What If API</a></strong> &#8211; Use the What If tool with the Microsoft Graph API to evaluate programmatically the applicability of Conditional Access policies in your tenant on user and Service Principal sign-ins.</p>
</li>
</ul>
